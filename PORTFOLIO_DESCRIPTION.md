# Portfolio Description

## GitHub description

ROS 2 Humble TurtleBot3 workspace setup for simulation, teleoperation, SLAM/navigation, and manipulator integration using Gazebo, Nav2, Cartographer, MoveIt 2, and Dynamixel tooling.

## CV version

Configured and tested a ROS 2 Humble TurtleBot3 development environment integrating Gazebo simulation, keyboard teleoperation, Cartographer SLAM, Navigation2, MoveIt 2 manipulation packages, and Dynamixel tooling; created and preserved an occupancy-grid map for navigation experiments.
